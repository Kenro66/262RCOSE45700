## 验收题 A01–A10

### A01｜提前填写电子申报后的口岸手续

**问题：** 我携带需要向中国海关书面申报的行李物品入境，已经提前在微信小程序填写电子申报数据，到口岸后还需要确认数据吗？应该走哪个通道？

**Category：** 正常回答与 Citation。

**预期：** `ANSWERED`。提前填写不等于已经完成口岸手续；进境时仍须在申报台等指定地点确认相关数据、接受海关验核并办理手续，应选择红色通道。

**适用/缺失条件：** 中国入境；已明确携带应书面申报物品，无须再次追问物品是否需要申报。

**证据 [CN03，PDF物理第3页，第五项]：**

> 进出境时，在申报台等指定地点确认相关数据，并接受海关验核，办理相应手续。

**证据 [CN03，PDF物理第1页，第一项]：**

> 向海关书面申报，选择“红色通道”通关。

**Expected Behavior：** 直接解释手续，引用覆盖“到场确认”和“红色通道”两项结论。不得回答“网上填完即可直接通关”；证据充分后停止补检索。

### A02｜缺少商业用途限制时不得猜测免税结论

**问题：** 我准备把境外购买、金额低于一般免税额的物品带入中国后用于销售，可以按个人自用物品免税放行吗？

**Category：** Evidence Check：关键适用依据缺失；需 Mock。

**预期：** `INSUFFICIENT_EVIDENCE`。在本题受限证据下拒绝给出确定的免税或征税结论。允许“现有证据不足，无法确认相关政策”“不能仅凭金额门槛确认该用途是否适用免税”等等价表述，不要求逐字匹配或必须解释具体缺失条款。

**适用/缺失条件：** 中国入境；已提供成年中国居民、非经常出入境人员、非运输工具工作人员等身份条件；用途明确为销售。缺少的是政策对用途的限制依据，不是用户条件。这些已知条件随原问题一并传入，避免本题意外转为身份追问。

**证据 [CN01，PDF物理第2页，第十一条；仅作为受限输入]：**

> 对进境居民旅客携带在境外获取总值五千元人民币以内的行李物品，进境非居民旅客携带拟留在境内的总值两千元人民币以内的行李物品，海关予以免税放行。

**审核依据 [CN01，PDF物理第3页，第十四条；本题不提供给 Agent]：**

> 仅限于个人自用，不得用于商业用途。

**Expected Behavior：** 识别“金额范围”不能单独证明“商业用途也免税”，不得依靠模型记忆补充被隐藏的用途限制。本题拒答针对受限输入，不代表完整政策没有答案。PASS 条件为：状态正确、`answer` 为空、`citations` 为空、无新增 Retrieval，且拒答提示未夹带无当前证据支持的确定性政策结论；不得仅因合理拒答措辞不同判 FAIL。

**Test Setup：** 从可信服务端状态恢复，`retrieval_count=3`，缓存仅包含上述第十一条摘录；不提供第十四条或其他用途限制证据。实际新增 Retrieval 必须为 0。仍直接判定“低于额度即可免税”，或给出其他无当前证据支持的确定性政策结论，均判为失败。

### A03｜证据充分时不因无关额度规则拒答

**问题：** 我收到一件个人自用、非商业用途的进境寄递物品，海关核定的应征税额恰好是人民币50元，可以免税放行吗？

**Category：** Evidence Check：核心证据充分、避免过度拒答。

**预期：** `ANSWERED`。可以；“五十元人民币以内”包括恰好五十元。不得把旅客行李物品的价值额度套用于本题。

**适用/缺失条件：** 进境寄递物品；个人自用、非商业用途；应征税额已经海关核定。

**证据 [CN01，PDF物理第3页，第十三条]：**

> 对应征税额在五十元人民币以内的寄递物品，海关予以免税放行。

**证据 [CN01，PDF物理第3页，第十四条]：**

> 本办法第十一条、第十二条、第十三条规定的免税数额以内的进境物品，仅限于个人自用，不得用于商业用途。

**Expected Behavior：** 根据税额门槛和用途条件回答，并引用。不得再追问居民身份、旅客免税额度或烟酒限量，不为寻找这些无关条件继续改写检索。

### A04｜补检索找到别送品的到达期限

**问题：** 我作为普通旅客入境韩国，另用其他运输工具运来的别送品，通常需要在我入境后多久到达，才符合该项免税规定的到达期限要求？

**Category：** Query Rewrite：补检索成功；需 Mock。

**预期：** `ANSWERED`。除自然灾害等不可避免的情形外，应在旅客入境之日起六个月内到达。该期限条件不等于满足后自动获得全部免税资格。

**适用/缺失条件：** 韩国入境；普通旅客；询问别送品的通常到达期限，不是搬家物品或乘务员物品。

**首轮证据 [KR01，PDF物理第1页，第2条第5项]：**

> "별송품"이란 여행자가 이용한 항공기 또는 선박 등 이외의 운송수단을 이용하여 별도로 반입하는 물품을 말한다.

**补检索证据 [KR02，PDF物理第27页，第48条第6款]：**

> 법 제96조제1항제1호에 따른 별송품은 천재지변 등 부득이한 사유가 있는 경우를 제외하고는 여행자가 입국한 날부터 6월 이내에 도착한 것이어야 한다.

**Expected Behavior：** 首轮只有定义，不能据此回答期限；Rewrite 保留韩国、旅客、别送品及免税到达期限等关键信息。第二次取得期限及例外后回答，不再执行第三次检索。

**Test Setup：** 第一次 Retrieval 仅返回定义；第二次返回第48条第6款完整条款。证据补全依赖不得提前提供期限。通过条件为实际 Retrieval 两次、出现有效改写、最终答案含六个月及不可避免情形的例外，并引用期限原文。

### A05｜补检索仍缺乘务员专用额度时拒答

**问题：** 韩国国际航班的机组人员携带自用物品入境，一般免税金额上限是多少？

**Category：** Query Rewrite：补检索仍不足；需 Mock。

**预期：** `INSUFFICIENT_EVIDENCE`。说明缺少适用于国际航班机组人员的额度依据；不得用普通旅客额度代替，也不得从模型记忆给出数字。

**适用/缺失条件：** 韩国入境；国际航班机组人员；询问一般携带物品的金额额度，不是酒或烟的单独免税数量。

**受限证据 [KR01，PDF物理第1页，第2条第2项，摘录]：**

> "승무원"이란 국제무역선(기)에 탑승하여 근무하는 것을 직업으로 하는 자

**受限证据 [KR01，PDF物理第8页，第18条第1款，连续摘录]：**

> 관세의 면제 한도는 여행자 1명이 반입한 제4조에 따른 여행자 휴대품으로서 각 물품의 과세가격 합계 기준으로 미화 800달러 이하(이하 "기본면세범위"라 한다)로 한다.

**审核依据 [KR02，PDF物理第28页，第48条之3第1款第1项；本题不提供给 Agent]：**

> 국제무역기의 승무원이 휴대하여 수입하는 물품: 미화 150달러

**Expected Behavior：** 识别普通旅客与机组人员的适用对象不同；围绕机组人员专用规定改写并补检索。仍未取得关键条款时拒答，不执行第四次 Retrieval。

**Test Setup：** 各次 Retrieval 均仅返回上述身份定义和普通旅客条款，不返回第48条之3或等价证据；禁止补全依赖泄露该条款。分别记录：

- **正确拒答：** 返回 `INSUFFICIENT_EVIDENCE`，不输出确定额度，累计 Retrieval 不超过 3；允许合法提前停止。
- **Query Rewrite：** 还须观察到至少一次针对机组人员专用规定的有效改写及随后的实际补检索，查询不重复，累计 Retrieval 为 2–3 次。若没有改写或没有实际补检索，记录“未覆盖”，不得宣称 Rewrite 通过；只满足正确拒答不能算本题全部通过。

### A08｜同一适用范围内出现真正相反的模拟规则

**问题：** 普通成年旅客将测试物品 X 带入测试场景中的中国境内时，是否需要书面申报？

**Category：** Conflict Check：True Conflict；**TEST ONLY / 需 Mock**。

**预期：** `CONFLICTING_EVIDENCE`。展示双方模拟证据及冲突原因，不自行裁决“需要”或“不需要”。

**适用/缺失条件：** 两条模拟证据均为中国入境、普通成年旅客、个人自用、同一物品 X、2026年全年有效；无上下位优先或替代关系。

**模拟证据 A：**

> 普通成年旅客携带个人自用的测试物品 X 入境，必须书面申报。

**模拟证据 B：**

> 普通成年旅客携带个人自用的测试物品 X 入境，无需书面申报。

**证据来源：** 测试桩中的 `TEST_ONLY_A.pdf` 第1页和 `TEST_ONLY_B.pdf` 第1页。二者仅为**虚拟来源定位信息，不是真实政策文件**，不属于五份政策 PDF。

**Expected Behavior：** 说明同一适用范围下，双方对书面申报义务给出无法同时成立的结论。冲突双方 Evidence ID 均能映射到各自模拟 Citation，原文不得混用。

**Test Setup：** 一次 Retrieval 同时返回两条模拟证据及相同适用范围元数据；只控制证据，不预设冲突判断。通过条件为冲突状态、双方出处完整、原因非空、无确定性裁决。不得标记为真实政策冲突验证通过。

### A09｜不同国家的免税标准不构成冲突

**问题：** 我在韩国买了一些准备带回中国自用的普通物品。韩国资料和中国资料对旅客免税额度的说法不一样，这次回中国该按哪一套规定办理？

**Category：** Conflict Check：国家及入境方向不同。

**预期：** `ANSWERED`。两者适用的国家不同，不构成 True Conflict。本题询问中国入境，应依据中国居民旅客的相应规定判断，不能套用韩国入境标准。

**适用/缺失条件：** 测试前置条件为中国入境、成年中国居民普通旅客、非经常出入境人员、非运输工具工作人员；物品为个人自用、非商业用途，排除烟酒及特殊管理品类。上述已知条件随请求或可信状态提供给 Agent，不作为隐藏信息；不将标准答案、数额或“无冲突”结论写入用户问题。

**证据 [KR01，PDF物理第8页，第18条第1款]：**

> 각 물품의 과세가격 합계 기준으로 미화 800달러 이하

**证据 [CN01，PDF物理第2页，第十一条，连续摘录]：**

> 对进境居民旅客携带在境外获取总值五千元人民币以内的行李物品，进境非居民旅客携带拟留在境内的总值两千元人民币以内的行李物品，海关予以免税放行。

**证据 [CN01，PDF物理第3页，第十四条]：**

> 仅限于个人自用，不得用于商业用途。

**Expected Behavior：** 区分韩国入境与中国入境的适用范围，不通过比较金额大小决定政策优先级。解释差异并引用对应国家依据，不返回 `CONFLICTING_EVIDENCE`。

### A10｜跨请求累计三次检索后必须停止
